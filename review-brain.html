Behind the build

A $5 side project that became
a marketing superpower

No engineers. No complex infrastructure. Just a smart use of existing tools and a clear problem to solve.

1
Extracted all reviews via API
$5 spent on a Trustpilot scraping API to pull all 3,000+ reviews as raw data — reviewer names, dates, ratings, text, and brand responses included.
2
Cleaned and structured the data
Manually sorted and formatted raw reviews into a structured .md file with consistent fields, clean text, and ready to read as a knowledge base.
3
Uploaded to a Claude Project
The .md file became the knowledge base for a dedicated Claude Project — giving the AI full context of every customer review ever written about Nyrah.
4
Wrote strict marketing instructions
Custom system instructions train Brand Brain to think like a conversion copywriter — filtering by emotion, product, outcome, objection, and audience intent.
$5
Total investment: $5 and an afternoon
Outcome: an always-on testimonial intelligence tool for every campaign Nyrah runs — forever.
