Part 01

Semrush — Step by Step

Execute these in exact order. Do not jump ahead. Each step feeds the next.

01
Set up the Nyrah Beauty project One-time setup — your persistent workspace

Open Semrush → click Projects in the left sidebar → Create Project → enter Nyrah Beauty's domain → name it "Nyrah Beauty SEO" → click Create.

This creates a persistent workspace. Everything you research, audit, and track lives here across all sessions. Do not skip this step — running tools outside a project means you lose continuity.

02
Run a Site Audit immediately This feeds the entire fix list — start it first

Inside the project → Site Audit → configure: set crawl limit to all pages, enable all issue types, set user agent to Googlebot → Start Site Audit.

It takes 5–20 minutes. While it runs, move to keyword research. Come back when done.

When it finishes: Export the full issues report as CSV. Filter by Errors first → then Warnings → then Notices. Do not touch Notices until every Error and Warning is resolved. This report is your Week 1 fix list.
03
Set up Position Tracking Baseline before you publish a single word

Inside the project → Position Tracking → set target country to Ireland → device: Desktop → add these seed keywords manually:

hormonal skin
fragrance-free skincare
bakuchiol vs retinol
daily SPF Ireland
self-tan sensitive skin
perimenopausal skincare
rosacea skincare routine
hyaluronic acid serum

Click Start Tracking. You will get zero or near-zero rankings — that is expected. This is your baseline. Check it every two weeks to measure movement as content goes live.

04
Competitor benchmark Find 2–3 comparable brands and steal their keyword gaps

Go to Keyword Overview → enter the domain of a comparable brand (fragrance-free or hormonal skincare, Ireland/UK focus — e.g., Pestle & Mortar, Skingredients, or a similar indie brand) → look at their Top Organic Keywords report.

Apply these filters:

KD: 0–35 Volume: 100–3,000 Country: Ireland + UK

Export this as CSV. Any keyword they rank for in this range is achievable for Nyrah. These become your validation list — if they rank for it, the domain authority threshold is reachable.

Do this for 2–3 competitors separately. Do not merge — keep competitor data in separate tabs in your master sheet so you know where each keyword came from.
05
Keyword Magic Tool — Pillar by Pillar The core research step — 5 pillars, run in sequence

Go to Keyword Magic Tool in the left sidebar. Set country to Ireland. Apply these global filters before every single search:

KD: 0–35 Volume: 100–3,000 Intent: Informational (first pass)

After your first pass on each pillar, run again with Intent set to Transactional to catch purchase-intent variants.

For every seed keyword, follow this exact process:

  1. Type the seed → Search
  2. Look at Broad Match tab → scan and filter → export CSV
  3. Switch to Questions tab — this is the AEO tab. Every question with volume 100+ and KD under 30 is a candidate blog topic. Export this separately.
  4. In the SERP Features column: flag any keyword showing AI Overview, Featured Snippet, or People Also Ask → mark as AEO Priority: Y in your sheet
  5. Label exports clearly: P1_hormonal-skin_broad.csv / P1_hormonal-skin_questions.csv

06
Topic Research Tool — trend validation Identify rising subtopics before competitors do

Go to Topic Research in the left sidebar. Search these topics one by one:

hormonal skin → rosacea skincare → bakuchiol → SPF daily → self-tan sensitive skin

For each topic, look at two things:

  1. Trending Subtopics (top right of each card) — any subtopic showing a rising trend in the past 6–12 months is a priority cluster blog. Rising demand + thin content supply = the ideal gap for a new domain.
  2. Questions tab inside each card — record every question with high engagement that does not have a strong existing answer. These are your highest-priority AEO blog topics across the entire plan.
A rising trend subtopic that also appears in the Questions tab with no strong existing answer is a Tier 1 priority — schedule it within the first 10 weeks regardless of where it falls in the original cluster sequence.
07
Compile the master keyword sheet The single source of truth for every brief

At the end of all Pillar 1–5 research, your Google Sheet should contain approximately 80–150 keywords. Create these columns:

Pillar | Cluster Blog # | Keyword | Monthly Volume (IE) | KD | Intent | SERP Features | AEO Priority (Y/N)

Then do this in order:

  1. Sort by AEO Priority: Y first
  2. Within AEO Priority: Y, sort by KD ascending (lowest competition first)
  3. Assign each keyword to its cluster blog (C1.1, C1.2, etc.)
  4. Mark one primary keyword per blog (highest relevance + lowest KD)
  5. Mark 3–5 secondary keywords per blog (related questions and variants)

This sheet is the brief input for every blog going forward. No blog brief is written without a row in this sheet first.

Final validation step: After shortlisting, go to Keyword Overview and check each primary keyword one at a time. Look at who is currently ranking — if page 1 is dominated by WebMD, Healthline, and Vogue, the KD score is lying and that keyword is harder than it appears. Find the variant with a weaker SERP.

Part 03

Critical Execution Rules

Non-negotiable. These govern every decision from Day 1 to Day 90.

Blog redirect process
Handle existing blogs with precision
Before deleting any existing blog, run the Semrush Backlink Audit on that URL. If any external backlink exists: 301 redirect to the most relevant new pillar blog URL once it is live. If zero backlinks and zero GSC traffic: safe to delete. Document every URL decision before touching anything: old URL → action → redirect destination.
Publishing pace
Two blogs per week — intentional, not slow
Publishing too fast on a new domain with no topical authority looks unnatural and delivers no compounding benefit. Two per week gives Google time to crawl, index, and begin associating the site with the topic cluster before the next layer arrives. This pace is disciplined, not conservative.
Semrush rhythm
Check Position Tracking every two weeks
Run Position Tracking every two weeks minimum. Check Google Search Console impressions (not just clicks) every week — impressions appear before clicks. Rising impressions with zero clicks means the content is indexing and relevant, but the title or meta description needs refinement. Fix the meta before assuming the content is wrong.
Product page timing
Rewrites run parallel to early content
Product page rewrites happen in Weeks 4–6 alongside early blog publishing. These are permanent pages — not blogs — and must be optimized before blogs start sending internal link equity their way. A blog linking to a product page with a thin description and no schema is wasted internal link equity.
Absolute rule — no exceptions
Do not publish outside the pillar-cluster map
Do not add any new blog to the schedule that is not already in the pillar-cluster map until all 18 mapped blogs are live and all properly interlinked. Topical authority builds from completeness within a cluster — one orphan blog outside the map does zero work. One complete, fully-interlinked cluster is worth more than 30 disconnected blogs chasing random keywords. The map is the plan. The plan is the law.
